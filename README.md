Le Chevreuil est un moteur de jeu RPG par navigateur conçu pour une immersion totale via une interface de Mapping Absolu. Le système superpose des données dynamiques (HP, XP, Primes) sur une direction artistique fixe, garantissant un rendu visuel haut de gamme et une performance optimale sans rafraîchissement de page. L'architecture technique repose sur Node.js et Express pour le serveur, Socket.io pour la communication en temps réel, et une sécurité renforcée par JWT et Bcrypt. Le projet est structuré avec un dossier /public pour le front-end (contenant le mapping CSS précis et la logique client) et des modules back-end dédiés à la logique métier (models.js) et aux calculs de duels (combat.js). Pour lancer le moteur, installez les dépendances avec npm install, configurez votre secret JWT dans un fichier .env, puis démarrez avec npm start. Toute modification de la disposition visuelle s'effectue directement dans le fichier style.css en ajustant les coordonnées de positionnement relatif.
